# 🚕 Samra Taxi

**Samra Taxi** is a simple, modern, and responsive website for a taxi stand and taxi booking service. The website helps customers learn about available taxi services and quickly contact the taxi stand for bookings.

## 🌐 Features

* 🏠 Modern and responsive homepage
* 🚕 Taxi service information
* 📞 Easy phone-call booking
* 💬 WhatsApp booking/contact
* 📍 Location and contact information
* 📱 Mobile-friendly design
* ⚡ Fast and lightweight
* 🎨 Clean and professional UI

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Interactive features

## 📁 Project Structure

```text
Samra-Taxi/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The website will open in your web browser.

## 🌍 Deploy for Free

You can host this website for free using **GitHub Pages**.

1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Select your main branch.
5. Save the settings.
6. GitHub will provide your website URL.

## 📞 Booking

Customers can contact Samra Taxi through the phone or WhatsApp buttons available on the website to request a taxi or make a booking.
